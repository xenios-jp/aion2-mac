# Contributing

Use a separate bottle and report your exact Mac model, memory, macOS version, toolkit version, game build, renderer, resolution and MSync setting. Distinguish a component probe from observed gameplay. Include reproducible steps and concise redacted diagnostics.

Do not submit game files, Apple libraries, credentials, launch tickets, Steam userdata, or anti-cheat bypasses. Runtime changes require revalidating the errno TEB layout and PE/Unix decoder ABI. Keep the default setup simple; experimental features should be explicit options.
